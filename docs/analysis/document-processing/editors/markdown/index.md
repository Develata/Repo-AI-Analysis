# Markdown 编辑与阅读工具

> 本目录收录以 Markdown 文件为主要对象的桌面编辑器、只读阅读器与系统预览工具。只读工具也归入此应用层分类；不因此把它们描述为编辑器。逐项评分、支持边界与证据见各分析页。

## Files

- [Tinta](./tinta.md) — Windows 原生 Markdown / Mermaid 阅读工具，附带编辑能力。
- [FastMarkdownViewer](./fastmarkdownviewer.md) — 面向 Windows、macOS 与 Linux 的原生只读阅读器。
- [rmdv](./rmdv.md) — Rust 桌面阅读工作区，提供 CLI / IPC 控制入口。
- [MDViewer](./md-viewer.md) — macOS 预览应用与 Finder Quick Look 扩展；注意签名与 HTML 渲染边界。
- [Markdown Viewer (mdview)](./mdview.md) — 基于 Electron 的跨平台独立只读阅读器。

## Subdirectories

无子目录。

文档转换、PDF 提取与 OCR 工具归入 `document-processing/document-conversion/`；通用排版、技术出版与其他文档编辑工具保留在 `document-processing/editors/`。
